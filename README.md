# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 武器分支构筑

每件武器升至 **Lv.3** 时进入分支节点，该次升级只能在两个弹道分支中二选一，并在本局内永久锁定。分支会改变实际的发射方式、命中规则与穿透能力；发射瞬间的属性会复制到弹体上，因此分支选择不会追溯影响已经在途的弹体。

| 武器 | 分支 A | 分支 B |
| --- | --- | --- |
| 脉冲步枪 | 散列脉冲：5 发扇形齐射，单发伤害降低 | 轨道磁轨：单发高速贯穿，额外穿透 2 个目标 |
| 环轨飞刃 | 回旋刃轮：抵达射程后折返，返程可命中未被击中的目标 | 裂片环轨：飞刃 +3，双层环轨错峰发射 |
| 新星爆发 | 连锁新星：命中后分裂 3 枚追踪星屑 | 超载新星：星环 -4，伤害 ×1.55，弹体扩大 |

- 分支节点期间战场冻结，候选只包含该武器的两条合法分支，无法用普通等级绕过节点。
- 达到 Lv.5 上限的武器会从升级候选中移除；全构筑满级时以「紧急修复」作为合法后继，不会出现扣除等级却无实际增强的选项。
- 右侧武器面板显示经全局加成后的真实参数（单发伤害、齐射数量、理论 DPS、射速、穿透、弹速）；结算面板与行动档案按武器与分支分别记录有效伤害。
